# 2G Simulator

## Описание
Это программное обеспечение предназначено для симуляции 2G-канала связи с поддержкой импорта характеристик канала из MATLAB Qudriga. Основные возможности:
- Генерация сигналов с различными типами модуляции (GMSK, QPSK, 16-QAM).
- Импорт реалистичных характеристик канала из `.mat`-файлов.
- Анализ метрик (BER, SER, пропускная способность) и визуализация результатов.
- Применение алгоритмов демодуляции (MLSE, Viterbi).
